# Next Run Club Braga 🏃‍♂️🇵🇹

Plataforma oficial da **Next Run Club Braga** — uma comunidade aberta, gratuita e inclusiva de corrida e convívio na cidade de Braga, Portugal.

🌐 **Website Oficial:** [https://nextrunbraga.github.io/](https://nextrunbraga.github.io/)

---

## ⚡ Sobre o Projeto

O Next Run Club nasceu com o lema *"Mais do que Apenas Correr"*, reunindo entusiastas do esporte, desde iniciantes que nunca correram até maratonistas experientes. A plataforma web oferece todas as informações necessárias para quem quer se juntar aos treinos, conhecer os pacers, calcular o ritmo ideal e fazer parte da comunidade.

### Principais Funcionalidades

- **Design Moderno & Responsivo:** Interface escura e elegante estilizada com Tailwind CSS.
- **Internacionalização (i18n):** Suporte multilíngue integrado para atender à comunidade cosmopolita de Braga.
- **Calculadora de Pace & Squads:** Ferramenta interativa para corredores encontrarem o seu squad de treino de acordo com a velocidade pretendida (Walk & Run, Social, Endurance, Speed).
- **Galeria & Momentos:** Registos visuais das sessões de treino e percursos emblemáticos da cidade.
- **Perguntas Frequentes (FAQ):** Accordion dinâmico esclarecendo pontos de encontro, segurança e rotina.
- **Otimização SEO & OpenGraph:** Metatags completas, dados estruturados (Schema.org JSON-LD) e alta velocidade de carregamento.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **Tailwind CSS** (via CDN com temas e utilitários customizados)
- **JavaScript Moderno (ES6+)** para interações, cálculo de ritmo e motor de tradução
- **Font Awesome 6** para ícones
- **GitHub Pages** para hospedagem estática global e segura
